\# 第一次 Git 实验总结

1\. git add 的作用是？

git add 将工作区的改动添加到git暂存区，为后续commit做准备。



2\. git commit 的作用是？

把暂存区里的改动保存成本地版本库的一次提交，生成commit快照。



3\. 本次实验中 git restore notes.md 的作用是？

丢弃工作区还没提交的修改，把notes.md恢复到上一次commit的状态，撤销本次修改。



4\. commit 与 push 的区别是？

commit仅仅保存到你本地电脑的git仓库；push把本地已经commit过的提交上传到GitHub远程仓库。
