# 我的 Git 学习笔记

## 第⼀次 Git 实验总结

1. `git add` 的作⽤是：将工作区中文件的新增、修改、删除等变更提交到暂存区，为gIt commit提交版本做准备。

2. `git commit` 的作⽤是：将暂存区已经暂存好的文件改动，正式保存到本地版本仓库，创建一条新的提交记录。

3. 本次实验中 `git restore notes.md` 的作⽤是：撤销工作区还没被 add 的修改，即撤回追加“这是一句准备放弃的练习文字”这一修改。

4. `commit` 与 `push` 的区别是：commit是把改动提交到本地仓库，仅保存在自己的电脑，这一过程不依赖网络；而push是将本地仓库的版本记录上传同步到远程仓库，需要依赖网络链接远程仓库。
